# Gauri Sikarwar - Personal Portfolio Website

A modern, responsive, high-performance personal portfolio website built for **Gauri Sikarwar** (B.Tech Student at JECRC University, Jaipur).

## 🚀 Built With

- **React 18** – Modern UI component library
- **Vite** – Lightning-fast build tool and dev server
- **Tailwind CSS** – Utility-first CSS framework with custom glassmorphism and animations
- **Lucide React** – Clean, modern SVG icons
- **Vercel Ready** – Ready for instant zero-config deployment

## 🌟 Features

- **Hero Section**: High-impact introduction, interactive developer profile card, and quick call-to-actions.
- **About Me**: Student-friendly narrative, core tech pillars, and quick statistics.
- **Education**: Detailed B.Tech degree path at JECRC University, Jaipur with relevant coursework areas.
- **Skills**: Attractive, interactive skill cards for Python, Artificial Intelligence, Generative AI, Web Development, and Digital Productivity.
- **Projects**: Showcase of Personal Portfolio, AI Website Project, and Student Productivity Project with modal previews and repository links.
- **Achievements**: Tabbed category filters (Certifications, Hackathons, Courses, Awards) designed for easy updates.
- **Contact**: Direct email with 1-click clipboard copy, LinkedIn, GitHub, location tag, and interactive contact form.
- **Dark & Light Mode**: Seamless theme switching with persistent CSS variable support.
- **Fully Responsive**: Mobile-friendly navigation drawer and responsive grids across all devices.

## 🛠️ Getting Started Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview the production build:**
   ```bash
   npm run preview
   ```

## 🌐 Deploy to Vercel

1. Push this repository to your GitHub account (`https://github.com/gaurisikarwar/personal-portfolio`).
2. Log in to [Vercel](https://vercel.com) and import the repository.
3. Keep the default settings (Framework preset: `Vite`, Build command: `npm run build`, Output directory: `dist`).
4. Click **Deploy**!
